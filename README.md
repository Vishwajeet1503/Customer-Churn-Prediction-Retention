## 📌 Project Overview

Customer churn is one of the biggest challenges faced by telecom companies.  
This project focuses on analyzing customer behavior, identifying churn patterns, and providing data-driven retention strategies using **Python, SQL, and Power BI**.

The analysis was performed on a telecom customer dataset containing **7,043 customer records**, with the goal of discovering the major factors contributing to customer churn and helping businesses reduce customer loss.

---

## 🎯 Objectives

- Analyze customer churn behavior in the telecom industry
- Identify high-risk customer segments
- Explore patterns based on contract type, tenure, internet service, and payment methods
- Build an interactive Power BI dashboard for business insights
- Recommend retention strategies to improve customer loyalty

## 🔍 Project Workflow

### 1️⃣ Data Cleaning & Preparation
- Removed missing and inconsistent values
- Handled formatting issues
- Checked for outliers and duplicate records
- Prepared structured data for analysis

### 2️⃣ Exploratory Data Analysis (EDA)
- Analyzed customer demographics and service usage
- Identified churn distribution across multiple categories
- Compared churn trends by contract type and tenure

### 3️⃣ SQL-Based Customer Segmentation
Used SQL queries to segment customers based on:
- Contract type
- Service usage
- Tenure groups
- Payment methods

### 4️⃣ Dashboard Development
Created an interactive Power BI dashboard with drill-through filters and KPI tracking.

- 💳 Churn by Payment Method

---

## 📈 Key Insights

- Customers with **month-to-month contracts** showed a churn rate nearly **3x higher** than yearly subscribers.
- Customers using **electronic check payment methods** had higher churn tendencies.
- Short-tenure customers were more likely to leave the service.
- Lack of additional services such as **online security** and **tech support** increased churn probability.

---

## 💡 Business Recommendations

Based on the analysis, the following retention strategies were recommended:

- Offer discounts or loyalty rewards for long-term contracts
- Create targeted offers for high-risk customers
- Improve onboarding experience for new customers
- Promote bundled services like online security and tech support
- Encourage automatic payment methods for better retention
